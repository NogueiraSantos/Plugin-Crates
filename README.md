Plugin Vibecodado com utilização do Opus 5 bem simples sobre caixas nada de roleta

Comandos:
/crate create {nome} -
/crate set {nome}- 
/crate unset {nome} - 
/crate edit {nome} - 
/crate key give {caixa} {jogador} {qtd} - 
/crate key remove {caixa} {jogador} {qtd} - 
/crate key set {caixa} {jogador} {qtd} - 
/crate key all {caixa} {qtd} - 
/crate list - 
/crate delete {nome} - 
/crate reload

Mensagens configuráveis
Nome das caixas configuráveis em crates.yml

Sistema Anti-Dupe:
O item que está dentro da caixa passar a receber um valor numérico e evitando de pegá-lo caso exista dois existentes

Versões em que o plugin suporta é dá 1.21+
